# 我怎样跟 Codex 一轮轮改片

这里按手上的工作写。我把相邻的请求合在一起，用第一人称重述。日语例句、试听版本和实际测点取自 EDIT&CODEX 的对话和交接记录。剪游戏广告和给另一条广告追加口播，是两次不同的制作。

## 短剧字幕

**第一轮，先把十集跑成初稿。** 我指定一批片源，比如第 1 到 10 集，让对话助手在本机逐集识别日语，把每句开头、结尾和候选词存到字幕里。过去要从空白时间线开始抄，现在可以直接看哪句话和表演对不上。

**第二轮，补听收音差的地方。** 实际流程用过 Whisper 起稿、Qwen 复核。现场背景盖住低声时，我会留着原声，另用 Demucs 或 BS-RoFormer 分出人声，再把难句送去识别。两份候选不一致，就回听前后几秒。台本帮我认专名，最后写进字幕的是演员说出口的词。

**第三轮，把字幕压在画面上看。** 我让 FFmpeg 用每集对应的 SRT 做一份审片副本，边看画面边校对整集。时间码对不对、字卡有没有压住下一句、气声有没有漏，这时候比较容易发现。

**第四轮，只修我点出的那一句。** 初稿把句末写成「ごめん、やるから」。我逐字标出「手を貸せ。ご褒美やるから」。Codex 把原先拆开的两条接回去，复查相邻字幕和编号，我再回看。在这部剧后来的带水印审片里，可以直接看到修正后的词。另一处短句当时也按我的批注改成「親分！いました！」。

## 游戏广告剪辑

这段制作跨了两个工程。前一条《Kingshot》里，我换过整段斜拍开场，试过压缩拖长的词、降噪和交接草稿。下面的烤鱼剪点、V3 评论框和三尺寸交付，都属于随后那条《Whiteout Survival》。

**第一轮，先让我看见游戏和达人在同一条时间线上。** 游戏往前走，画中画里的达人跟着反应。我要求实况段保留达人窗口，逐句选出自然的表演，分开摆好画面、原声和字幕。这样后面可以只改一句反应。

**第二轮，我指动作，Codex 调位置。** 食物烤好约在 36.37 秒，惊叹落在这里。42.83 秒东西还推不进，得让观众看到那一下卡顿。47.70 秒升级后出现第一份成品，这时才接「できた！」。看片时我也会指很小的问题。有张字幕字号是 42，下一张是 74，改动前后比了 47 张字幕卡，只改了点名的那张。

**第三轮，从导出的视频里再听一次。** 浏览器第一次导出的主对白晚约 88 毫秒，尾卡晚约 44 毫秒，两个位置有不同的偏移。分轨校正后再测，36 处对白、4 处尾卡起音都对齐。这是该次导出的复测记录。动画里的游戏画面按实际剪点重绘。

**第四轮，回来读一遍开场评论。** 发回竖版后，开头还有一处要改。跟读的对白可以一次一行，但演员正在回应的那条评论，观众得先看到全文。我请 Codex 把三行文字放回同一张卡片。把两版竖屏导出的前几秒放在一起，V3 上的句子轮流消失，V4 从弹出起就能一次读完。[看真实片段对照](edit.md)

**第五轮，逐个画幅回看。** 先定竖版，再按参考成片调整横版与 4:5 的真人取景、花字和小窗。工程最终留有一个原速备份和三条交付时间线。横版和 4:5 的后一次导出在制作时叫 V5，交付时三份文件统一按 V4 命名。

## 广告追加口播

**第一轮，现有录音里缺一段日语，我用同一位说话者的参考录音做试听。** 这次选 GPT-SoVITS v5 Turbo 起步，项目里已经有能在 T4 上跑通的环境。我确认了这次台词和参考人声的用途，再让 Codex 用正常语速整段合成。用片头连续说话的参考，第一份试听是 7.44 秒。

**第二轮，我希望更像片尾对着镜头说话的感觉。** 我们回到原片，改选片尾两段连续口播，去掉中间的长空白。还是同一段新台词，同一个模型、语速和随机种子，这次是 8.48 秒。一次只换参考，回听时才知道变化从哪里来。

**第三轮，我只想让开头平一点。** 我点名「A型ゲーマーとO型ゲーマー」。Codex 先做了一份局部试听，只收窄开头 2.16 秒的音高起伏。后面的声音逐采样对比完全一致。我听完又要求重新合成开头，说得自然一点，后文沿用原版。这个局部调整版留作前后对照，不能据此说我选了它交片。

**第四轮，我决定换模型听，而不是继续改同一条音频。** 重合成后我反馈声音出了问题，让 Codex 去试 Qwen。随后也用同样的词和参考试过 VoxCPM2，还听了 GPT-SoVITS v5 Dev。试听尽量匹配响度。我喜欢 v5 Dev 的语气，但听到一层「电音」；Qwen 听着干净，念起来却有点刻意慢。Codex 先把 v5 Dev 突出的高频收了一点，我认可了这版语气。

**第五轮，我把两个具体要求放到一起。** 保留原声的音色特征，让 Qwen 参照已经选出的 v5 柔化版节奏，重新念整句。两份候选里留了一条 7.92 秒的试听；旧 Qwen 是 8.96 秒。旧版开口到第一次明显停顿约 2.50 秒，语气示范约 1.88 秒，新版约 1.94 秒。这个数字帮我找到该来回听的位置。记录到新版试听导出为止，客户采用情况未记录。

### 动画里用了什么
